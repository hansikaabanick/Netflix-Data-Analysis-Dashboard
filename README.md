# 🎬 Netflix Data Analysis Dashboard

An interactive Netflix Data Analysis Dashboard built using Python, Pandas, Seaborn, Matplotlib, and Streamlit.

---

## 📌 Features

- Interactive Streamlit Dashboard
- KPI Cards
- Movies vs TV Shows Analysis
- Netflix Release Trend Visualization
- Top Content Producing Countries
- Most Popular Genres
- Sidebar Filters
- Clean Netflix-Themed UI

---

## 🛠️ Technologies Used

- Python
- Pandas
- Seaborn
- Matplotlib
- Streamlit

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/hansikaabanick/Netflix-Data-Analysis-Dashboard.git
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the Streamlit app

```bash
streamlit run app.py
```

## 📈 Insights Gained

- Netflix content increased rapidly after 2015
- Movies dominate more than TV Shows
- USA and India contribute the highest content
- Drama and International genres are highly popular
